# The Whisperer releases

This repository hosts Windows installers and signed update metadata for The Whisperer.

The application source archive is not published here. Recordings, transcripts, dictionary entries, settings, credentials and signing keys are never uploaded here.

Use the installer from the Releases page. Once the updater-enabled version is installed, use Preferences > Check for updates. The app verifies the publisher signature and installer checksum before offering an update. Checks are manual; no audio or transcript is sent.

The update signature is distinct from Windows Authenticode publisher signing. Windows may still show a warning for unsigned development software. Only proceed with downloads from the expected release source.

The app uses local speech models. See the installed third-party notices and licenses for dependencies and model terms.
